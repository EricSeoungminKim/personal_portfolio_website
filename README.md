# Seoungmin Kim — Portfolio

Personal portfolio built with Next.js 16, React 19, TypeScript, and CSS.

## Local development

```bash
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run lint` and `npm run build` before publishing.

## Updating content

- `src/data/portfolio.ts`: featured projects, experience, hackathons, and contact links
- `src/app/page.tsx`: home page copy and section order
- `public/Seoungmin_Kim_Resume.pdf`: downloadable résumé

The project visuals are editorial illustrations, not screenshots or performance reports. Motion respects the visitor's reduced-motion setting.
